🌱 Our Goal

This project demonstrates a crop recommendation workflow based on soil nutrients and environmental conditions.

The trained crop classifier and fitted preprocessing are loaded by Flask when the application starts.

Technology Structure

FrontendHTML + CSS + JavaScript
ML ModelTrained, selected classifier with probability estimates
BackendPython Flask API and sessions
DatabaseSQLite users and prediction history

Recommendation Flow

Frontend → authenticated Flask API → server-side validation → trained classifier → top three model probability estimates → SQLite history.
